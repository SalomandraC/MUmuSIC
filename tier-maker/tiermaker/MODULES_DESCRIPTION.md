# Описание модулей приложения MuMuSIC

## 3.1. Модуль управления состоянием приложения (app)

Данный модуль реализует функционал управления глобальным состоянием приложения, включая управление темой оформления (светлая/темная), языковыми настройками, состоянием авторизации пользователя (гостевой режим/авторизованный пользователь), а также обеспечивает централизованное управление маршрутизацией и навигацией между экранами приложения.

## 3.2. Модуль аутентификации (auth)

Данный модуль реализует функционал аутентификации пользователей, включая вход в систему, регистрацию новых пользователей и возможность входа в гостевом режиме. Модуль обеспечивает валидацию вводимых данных (email, пароль, никнейм) и управление сессиями пользователей.

## 3.3. Базовый модуль (core)

Данный модуль реализует базовый функционал, используемый во всем приложении, включая работу с локальной базой данных (Hive), взаимодействие с внешними API (iTunes API, API гостевых треков), навигацию между экранами через go_router, а также предоставляет переиспользуемые глобальные виджеты (например, PanelHeader) и утилиты для работы с данными.

## 3.4. Модуль работы с гостевыми треками (guest_tracks)

Данный модуль реализует функционал для работы с треками, загружаемыми с внешнего сервера для гостевых пользователей. Модуль обеспечивает загрузку списка треков, их воспроизведение через аудиоплеер, поиск треков по названию или исполнителю, а также управление воспроизведением (пауза, остановка, изменение скорости воспроизведения).

## 3.5. Модуль главного экрана и работы с сетью (home)

Данный модуль реализует функционал главного экрана приложения с навигационным меню, а также модуль поиска и работы с треками из сети iTunes. Модуль обеспечивает поиск треков через iTunes API с автоматическим debouncing, отображение списка найденных треков с обложками, предпрослушивание треков через previewUrl, скачивание треков на устройство с управлением разрешениями доступа к хранилищу, а также полнофункциональный аудиоплеер для воспроизведения найденных треков.

## 3.6. Модуль работы с NFC (nfc)

Данный модуль реализует функционал для работы с NFC-метками, включая чтение данных с NFC-меток, обработку полученной информации и интеграцию с системой воспроизведения треков на основе данных, полученных с NFC-меток.

## 3.7. Модуль настроек (settings)

Данный модуль реализует функционал управления настройками приложения, включая переключение между светлой и темной темами, настройку параметров подключения к API серверу, тестирование подключения к бэкенду, возможность поделиться приложением, связь с поддержкой и просмотр пользовательского соглашения.

## 3.8. Модуль темизации (theme)

Данный модуль реализует функционал управления визуальным оформлением приложения, включая определение цветовых схем для светлой и темной тем, настройку типографики, стилей компонентов интерфейса и обеспечение единообразного внешнего вида всех экранов приложения.
