- ✓ Строка на входе (все объекты, кроме одного)
- ✓ Структура данных на входе (ITunesSearchResponse.fromJson принимает Map)
- ✓ Структура данных на выходе (SearchTracksUseCase.execute, ITunesSearchResponse.fromJson)

## Запуск тестов

Для запуска всех тестов выполните:
```bash
flutter test
```

Для запуска конкретного тестового модуля:
```bash
flutter test test/itunes_track_test.dart
```

Для запуска с покрытием кода:
```bash
flutter test --coverage
```

## Примечания

1. Тест для `NetworkRepositoryImpl._sanitizeFileName` использует тестовый helper, так как метод является приватным. В реальном проекте рекомендуется сделать метод package-private для улучшения тестируемости.

2. Тесты для `AppDatabase` и `AppModel` требуют инициализации Hive, что выполняется в `setUp` и `setUpAll`.

3. Тесты для `SearchTracksUseCase` используют библиотеку `mocktail` для создания мок-объектов репозитория.

4. Один из тестов (`itunes_track_test.dart`) успешно выполнен и все тесты проходят.
