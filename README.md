# MUmuSIC

Музыкальный плеер на Flutter с серверным API и PostgreSQL. Клиент поддерживает поиск в iTunes, воспроизведение, локальные загрузки, личную фонотеку, плейлисты, избранное, синхронизацию, гостевой режим, топ-чарты и NFC-сценарии.

В репозитории находятся несколько поколений сервера. Для начала работы используйте `backend-java/`: его README и конфигурация описывают замену Node.js API с сохранением контрактов. Фактически развёрнутый сервер по содержимому репозитория определить нельзя.

## Карта репозитория

```text
MobileProject/
├── tier-maker/tiermaker/     Flutter-приложение (package: mumusic)
│   ├── lib/                 исходники приложения
│   ├── test/                unit- и widget-тесты
│   ├── assets/              иконки
│   └── android/, ios/, …    платформенные проекты
├── backend-java/            Java 21, Spring Boot 3.3.5, JDBC, Flyway
│   └── src/                 код, SQL-миграции и JUnit-тесты
├── backend/                 предыдущий API: Express + TypeScript
│   ├── server/              модули API и Jest-тесты
│   └── migrations/          SQL-миграции Node-версии
├── server/                  устаревший сервер с отключённым обычным запуском
│   └── storage/             общее действующее хранилище аудиофайлов
├── docs/                    архитектура и руководство разработчика
├── AGENTS.md                памятка для автоматизированной работы с кодом
└── ТЗ_ВКР_Подкопаев.md       требования и планы дипломного проекта
```

Исторические имена `tier-maker/tiermaker` не отражают текущее назначение приложения. В корне нет единого сборочного проекта: команды запускаются из каталога соответствующего компонента.

## С чего начать

1. Прочитайте [руководство разработчика](docs/DEVELOPMENT.md): настройка `.env`, запуск API и Flutter, проверки и типовые проблемы.
2. Используйте [карту архитектуры](docs/ARCHITECTURE.md), чтобы найти нужный экран, API или слой данных.
3. Детали Java-сервера находятся в [backend-java/README.md](backend-java/README.md); предыдущего Node-сервера — в [backend/README.md](backend/README.md).

Локальный стенд использует API `http://localhost:5050`, Swagger `/api-docs` и PostgreSQL на порту `5433`. Java- и Node-стенды используют одинаковые порты, имя Compose-проекта `mumusic` и том БД; запускать их одновременно не следует. `server/storage` содержит рабочие файлы и используется обоими стендами.

## Состояние и планы

ТЗ предусматривает Whisper, Demucs, очередь ML-задач и артефакты обработки. В просмотренных исходниках текущего приложения и API эти компоненты не реализованы. Метки «планируется» в ТЗ следует отличать от существующего поведения.

Обзор составлен по коду и конфигурации 14 ноября 2026 года. Старые документы местами называют `backend/` единственным сервером и описывают прежнее состояние проекта; при расхождениях проверяйте исходники и конфигурацию выбранного компонента.
